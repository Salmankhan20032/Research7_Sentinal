SENTINEL (**S**ecure and **E**vasion-aware **N**eural **T**rust **E**ngine for **I**ndustrial **N**etworked IoT **L**ayers) is an AI-driven, dual-model cybersecurity framework designed to safeguard Industrial Internet of Things (IIoT) layers from insider threats, compromised gateways, and low-and-slow behavioral evasion attacks. 

By logically decoupling the network-facing command broker from the deep learning-based Trust Engine, SENTINEL enforces a strict, hardware-binding **cryptographic write-gate** directly on physical sensor controllers. No physical state changes (writes) are executed without explicit, time-limited cryptographic approval.

---

## Core Security Features

- **Isolated Control Plane (Model A):** Hosts a Bidirectional LSTM with multi-head self-attention, processing temporal sliding windows ($W=32$) to generate suspicion scores.
- **Hardware-Binding Write-Gate:** Rejects physical state changes at the controller level unless accompanied by an unexpired, mathematically valid `HMAC-SHA256` token generated by Model A.
- **Active Honeypot Deception Layer:** Suspicious telemetry sequences are silently and transparently routed to a virtual sandbox. Attackers receive authentic-looking device write-acknowledgements, protecting the live process environment while logging the adversary's actions.
- **Protocol Agnostic Interface (Model B):** Deploys a high-throughput Go-based networking layer that marshals commands to Model A and manages client communication.
